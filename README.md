# 📚 Kitab Cart | Authentic Islamic Books Online Store

Kitab Cart is a modern, high-performance web application designed for selling authentic printed Islamic books, Quranic Tafseer, Sahih Hadith sets, Seerat-un-Nabi ﷺ, Islamic History, and Fiqh across Pakistan via **Pakistan Post Cash on Delivery (COD)** and **EasyPaisa**.

---

## 🌟 Key Features

- **🛒 E-Commerce Catalog & Real-Time Search**: Search Islamic books by Title, Author, ISBN, and Publisher.
- **📖 Digital Sample Excerpt Reader**: Preview authentic book chapters & excerpts in an interactive reader modal.
- **🚚 Pakistan Post Order Tracking**: Real-time shipment status tracker with registry tracking numbers (`TRX-XXXXXX`).
- **📱 EasyPaisa Payment Verification**: Instant payment screenshot upload & manual verification workflow.
- **🔒 Protected Owner Admin Portal**:
  - Secure login with Owner Secret Password (`t@hir27742`).
  - Full Inventory CRUD (Add, Edit, Inline Stock Adjustment, Delete books).
  - Customer Order Verification & Dispatch Status Management.
  - Announcement Offer Banner & Store Info Editor.
  - 1-Click Pakistan Post Courier Manifest CSV Export.

## 🚀 Quick Start & Installation

```bash
# 1. Clone the repository
git clone https://github.com/YOUR_USERNAME/kitab-cart.git

# 2. Navigate into project folder
cd kitab-cart

# 3. Start Node.js Server
node server/server.js
```

Open **`http://localhost:5000`** in your browser.
